## 📐 Image Optimization Guidelines

### Best Practices:
1. **Compression:** Use tools like TinyPNG or ImageOptim to compress images
2. **Format:**
   - Use **JPG** for photographs
   - Use **PNG** for logos and graphics with transparency
   - Consider **WebP** for modern browsers (fallback to JPG)
3. **Resolution:** Export at 2x resolution for Retina displays
4. **File Size:** Keep images under 500KB each for faster loading
5. **Alt Text:** All images in HTML have descriptive alt attributes for accessibility

### Recommended Tools:
- **Compression:** [TinyPNG](https://tinypng.com/)
- **Editing:** Adobe Photoshop, Canva, Figma
- **Stock Photos:** Unsplash, Pexels (for placeholders)
