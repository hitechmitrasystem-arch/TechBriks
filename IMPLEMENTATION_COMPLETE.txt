## 💡 Pro Tips

### Change Animation Speed
Edit line 514 in `public/js/main.js`:
```javascript
CONFIG.autoPlayDuration: 60000  // Change this number
```

### Change Number of Visible Logos
Edit `public/css/styles.css`:
```css
.carousel-item {
  width: calc(33.333% - 0.5rem);  /* 3 instead of 4 */
}
```

### Manual Controls in Console
```javascript
Carousel.pauseAnimation();     // Stop
Carousel.startAnimation();     // Resume
Carousel.setSpeed(40000);      // Change speed
```
